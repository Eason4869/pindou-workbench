# 拼豆工作台

当前发布交付版本：1.0.1。网页版、小黑盒构建包及源码包的使用和发布步骤见 [发布说明](../docs/releases/1.0.1.md)。

把 PNG、JPEG、WebP 图片转换成 MARD 拼豆图纸。支持像素图与普通图片、自动尺寸、29/58/32/64/96 格预设、自定义 1–200 格、等比补齐、颜色数量限制。提供带网格及坐标的预览、每个色号的实际数量、PNG、CSV 和真正的 PDF 文件。

## 安装与使用

需要 Node.js 22.20.0 或更高版本。进入本目录：

```powershell
npm ci --legacy-peer-deps
npm run dev:web -- --port 5173
```

打开 http://127.0.0.1:5173 。导入图片，设置尺寸和色卡，点击“生成设计图”，然后选择导出格式。修改图片或参数后需重新生成，导出始终取已生成的同一份图纸。色号与网格开关只影响屏幕显示，导出图纸始终带完整网格、色号与实际用量。

图片最大 8 MiB，解码尺寸上限为边长 8192 和总像素 1600 万。像素模式自动保留两边不超过 200 的原尺寸；其余输入自动将长边设为 64 格。小于 50% 的透明度留空，其余与白色合成。普通图片按面积平滑采样，无抖动。

## PDF 与用量

PDF 包含 A4 总览、用量清单及必要的清单续页、分块格子图。格子边长至少 5 mm，色号至少 7 pt；分块用全局行列坐标，从 1 开始，十格线加粗。中文字体随程序打包，导出时无须访问 CDN。为避免字体子集损坏，嵌入完整中文字体，典型 PDF 约 6 MiB。

用量为实际非空格数，不添加备料余量。孔距可以留空，填写后仅用于估算成品占用尺寸。PDF 并非按真实底板比例打印的摆放模板。

MARD 提供基础 221 色（A–H、M 系列）与全量 291 色。屏幕 RGB 是公开数据的参考值，请用实物色卡核对。其他品牌可在 `src/palettes.js` 的注册表添加，首版仅提供 MARD。

## 两种运行与构建入口

```powershell
npm run dev:web       # 独立浏览器，文件输入与浏览器下载
npm run build:web     # dist-web/，普通静态网站产物
npm run dev           # 官方 SDK 开发 Host，会打开浏览器预览
npm run build         # dist/，小黑盒 Manifest 与客户端入口校验
```

浏览器版不加载 SDK 握手。真实客户端的 production/preview 模式在握手 ready 后使用官方文件接口，连接期间禁用文件操作。原生导出先生成文件，再点击“保存文件”选择位置；不支持 saveFile 的客户端提供“选择保存文件夹”，需要新的一次点击授权，且不会覆盖已有同名文件。取消选择可重试；实际写入期间禁止取消、换图和替换文件。

官方 Browser Mock 的 iframe 没有 `allow-downloads`，它可以导入、生成和检查文件，但下载会被浏览器拦截。本工具明确提示此限制；下载文件请使用独立网页版，真机使用 SDK 保存。

官方小程序 CSP 禁止 Worker 和直接 fetch。浏览器版使用 Worker；小程序及官方 Mock 采用可中断的分段转换和分段 PDF 绘制，让页面持续响应。字体以按需加载的本地脚本载入，嵌入预压缩完整字体，避免在客户端同步压缩大字体。没有修改或放宽平台 CSP。

全部图片与转换在设备本地处理，不上传原图；只声明 filesystem 权限。小程序 ID 已由官方 CLI 绑定到发布目标；设备登录态不进入代码仓库。平台审核与上线状态需在 CLI 中核对，不能用本地构建代替实际发布。

## 验证

```powershell
npm test
npm run test:e2e
npm run hb-sdk -- doctor
```

端到端测试使用已安装的 Microsoft Edge（Playwright channel: msedge），验证真实文件导入、下载、错误保留旧结果、200×200 和 390px 布局，以及最大 PDF 导出期间的页面心跳。PDF 测试重新打开实际字节，逐个核对嵌入字形轮廓；有 Poppler 时另做独立字体渲染检查，没有安装时仅该检查跳过。SDK 文件错误边界和操作时序采用协议替身测试，不能代替真机。

真机需检查 Android/iOS/OHOS/Windows/macOS 的导入、取消、三种文件保存、目录降级、同名文件、授权撤回与分享后重开 PDF。正式发布前可补充各平台结果。

字体、公开色卡来源与许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。内置“小花”、图标、封面由代码原创绘制；用户提供的参考 PDF 未复制进入应用。
