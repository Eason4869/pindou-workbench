日期：2026-10-03（Asia/Shanghai）。当前任务为创建本地可交付的发布版本，未连接或修改远端小程序。

## 本次变更

- 应用和锁文件版本同步为 1.0.0；SDK 保持 0.8.4、其他依赖版本不变。
- 构建前同步字体、色卡及运行依赖的原始许可证/上游许可元数据到 `public/`，让两种生产构建与后续官方 CLI 提交都包含它们。
- 增加生产构建验收脚本和 Python 标准库归档工具。应用的转换算法、交互及文件保存行为不变。
- 发布目录与 ZIP 被 `.gitignore` 排除。源码包使用明确的文件白名单，包含 `app/` 和文档，排除依赖目录、构建目录、临时产物、`.git` 和 `.env`。

## 发布范围与未完成的远端步骤

网页版产物可直接用于静态 HTTP(S) 托管，小黑盒构建包可用于版本交付。官方 CLI 上传/提审会从源码重新构建。当前没有小程序 ID，没有上传、提审或发布，也没有 Git 提交或合并。

小黑盒目标平台仍需真实客户端文件读写验收，发布前在配置中仅保留验收通过的平台。Browser Mock 的下载限制与协议替身不能证明真机兼容。此项已明确写入发布说明和机器可读的包状态；没有把构建完成标为客户端已上线。

本任务重新读取官方 `llms.txt`、CLI、项目配置、兼容性表和稳定版更新日志；0.8.4 可继续使用。首次 Web 工具抓取超时后，通过网络读取官方原始 Markdown 成功，依据未使用过期本地快照。发布步骤见 `docs/releases/1.0.0.md`。
