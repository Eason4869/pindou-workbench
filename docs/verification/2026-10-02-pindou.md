## 已确认的实现取舍

1. 官方 SDK 的 CSP 禁止 Worker 与直接 fetch：浏览器版使用 Worker，客户端及 Mock 通过可中断的分段计算保持交互；字体由本地脚本按需加载。没有放宽 CSP 或增加网络权限。
2. CFF 和 TrueType 字体子集均出现字形损坏：改用完整预压缩 TrueType 和缓存度量，保留许可证及源文件校验值，以文件体积换取正确字形及客户端响应性。
3. 官方 Mock 的 iframe 没有 `allow-downloads`：明确报告“已生成、预览禁止下载”；独立网页实际下载，真实客户端走公开 SDK 文件保存接口。
4. SDK 间接依赖 sharp 原版本有生产依赖审计问题：仅覆盖该依赖至 0.35.4，构建与审计通过。
5. 全部图片在本地处理，仅声明 filesystem 权限；未绑定小程序 ID、部署、提交审核、推送或合并。
6. 保留本地分支与未提交的项目文件：上级仓库有其他项目改动，Git 作者未配置，按已批准计划不修改作者或全局设置。
