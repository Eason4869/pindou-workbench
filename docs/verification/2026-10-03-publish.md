## 当前验证

24 项 Node 测试通过，无跳过；7 项 Edge 端到端验收通过（28.1 秒）。两种生产构建通过，SDK Manifest 为 1.0.1 / 0.8.4，33 个可上传文件，10.3 MiB。

用户反馈顶部遮挡及点击 LOGO 后 `UNEXPECTED_DOCUMENT_LOAD`。回归先复现 SDK 提供 103px 顶部安全区时实际留白为 0；使用 `viewport.getWindowInfo()` 初值及 `viewport_change` 事件更新四边 CSS 变量，CSS 与浏览器 env 安全区取较大值。官方最新 `MiniProgramSafeArea` 明确坐标相对当前窗口，故不减去 screenTop。监听只初始化一次，销毁时取消；初始异步结果不覆盖更新事件。测试覆盖顶部/底部/侧边及变化后保留图纸。

官方 Host 复现点击 LOGO 时 iframe 再验证超时。原 `href=./` 导致整页导航；改为回到顶部，阻止导航，保留当前作品。用户随后确认触发操作确为点击 LOGO，且 Android 扫码已成功进入小程序。当前平台声明缩减为 Android，其他平台没有宣称真机通过。

修复后再次通过官方 Host 验证：顶部 SDK 安全区及 header.top 均为 99px，底部留白 34px；修改作品名称再点击 LOGO 后，名称保留、SDK 仍连接，等待超过原失败时间没有文档再验证错误。协议替身测试的父页等待初始生成后再替换 iframe，消除测试自身卸载 DOM 时的 Worker 竞态；该项重新运行通过。

生产网页根目录及 `/pindou/` 子目录验证通过：品牌资料与作者正确、关于信息可展开、透明 PNG 得到 3 颗、PNG/CSV/PDF 实际下载正确，未加载外部资源、无失败请求与未处理异常。官方尺寸 PNG 图标和封面通过检查。
